# Max-effort whole-codebase review

Tracking doc for a taskferry-dispatched, max-effort whole-repo review
(`reviewing-repos` skill) across correctness, security, and simplicity
focus modes. This PR exists to host the review's findings as a durable,
GitHub-visible artifact — no code changes are expected on this branch
unless the review surfaces something worth fixing directly.

Findings will be posted as PR comments per focus mode.
